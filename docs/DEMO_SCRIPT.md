# 三個情境的台詞卡

照著念就會觸發。對話仍然是真的 LLM——不是錄影、不是腳本回放——所以客戶的**用字每次都不一樣**，但被觸發的**行為**是固定的。下面每一格的「應該發生」講的是行為，不是逐字。

觸發之所以可靠，是因為三件事被釘住了：情境描述裡的【示範觸發】段落、客戶的開場白（引號內那句由伺服器直接播，不經模型），以及情緒門檻（四處都是 0.42：前端讀數下限、提示卡、伺服器的融合與客戶反應）。

演示前先確認：`curl -s 127.0.0.1:8795/healthz` 有回、右下角「說：本地／聽：本地」是你要的模式。本地語音只有一個女聲，男性客戶會用同一個聲音——這是已知取捨，見 HANDOFF §16.16。

## 情境三・自然互動（表情融合）— 主秀，30 秒

**進入**：模擬練習 → 續保費率調漲告知——不悅的張經理 → 設定練習 → 開始語音練習
**先開鏡頭**（輸入框旁的相機鈕），等右上角自己的畫面出現、標籤不再是「偵測中…」。

| # | 你講／做 | 張若瑄會說什麼（實跑錄下來的） |
|---|---|---|
| 1 | 什麼都不做 | **「我只有十分鐘，直接講重點。」**（這句是伺服器直接播的固定台詞，不經模型，所以逐字保證一樣） |
| 2 | 「張經理您好，這次續保費率要調整，我想先跟您說明原因。」 | 追問依據。實跑那次她說：**「132% 是怎麼算出來的？有沒有同業可以參考？」**——用字每次不同，但一定是追問數字來源或要同業對照。 |
| 3 | **對鏡頭皺眉兩秒**（或打字「這太離譜了。」） | 輸入框上方跳出教練的**提示卡**，問你需不需要協助；同時她在角色內確認一句「你好像不太認同我剛講的？」 |
| 4 | 點提示卡 → 「詢問教練」 | 教練卡長出具體建議，附逐字稿佐證。實跑拿到的是：**「先回答問題再補情緒——客戶現在最在意的是『132% 怎麼算的』，先用具體公式或理賠金額拆解」** |
| 5 | 「132% 是理賠金額除以年度保費，我把明細帶來了。」 | 她繼續追，實跑是：**「18% 對我們是百萬成本，同業大概漲多少？」** |

**表情沒被抓到時的備援**（鏡頭光線不好、或你天生不太皺眉）：直接打字「這太離譜了。」——文字路徑走同一套融合判讀。這不是作弊，是設計如此：文字與表情是兩個獨立訊號，文字那條有逐字證據，衝突時它贏。

> 這條備援**今天才真正接上**。之前情境描述寫「文字同樣有效」，但程式裡客戶只收得到表情訊號、收不到文字情緒，所以打字不會讓她確認——我實跑時打了「這太離譜了。」，她直接接著談數字。現在文字判讀改成跟知識查詢併行、在客戶開口**之前**就完成並送進去，所以兩條路都會觸發，而且沒有增加等待時間。

**不要念的**：具體調幅數字（例如「調漲 18%」）。念了會命中「受限制主題」，教練會當場開一張中風險合規卡——那其實是很好的示範，但它會把場子從情緒融合拉到合規去。想順便秀合規就故意念，想專心秀情緒就別念。

## 情境一・模糊意圖 → 反問釐清

**進入**：模糊提問的釐清對談——第一次買保險的林佳穎

| # | 你做什麼 | 應該發生 |
|---|---|---|
| 1 | 等她開口 | 林佳穎用半句話發問。 |
| 2 | 念一句**沒有指涉對象**的話：「這個划算嗎？」 | 她不會猜著回答，而是在角色內反問，並把可能的意思攤開：價格／保費、保障範圍、投資報酬、風險與除外。 |
| 3 | 選一個回答 | 她接著問下一個缺的資訊。 |

其他保證觸發的句子：「那這樣呢？」「要多少？」「有差嗎？」「這樣夠嗎？」

## 情境二・超綱話題 → 溫和收斂

**進入**：超綱話題的溫和收斂——健談的王伯伯

| # | 你做什麼 | 應該發生 |
|---|---|---|
| 1 | 等他開口 | 王伯伯先聊颱風跟投票，正事還沒開始。 |
| 2 | 念：「你覺得今天天氣如何？」 | 他以客戶身分短短帶過，然後自然把話題導回保單。**不會**說「我無法回答」。 |
| 3 | 念：「明天股票會不會漲？」 | 同上，且不做任何預測——這條在情境的 `restricted_topics` 裡。教練會標記離題並給收斂建議。 |

其他保證觸發的句子：「總統選舉你怎麼看？」「比特幣現在能買嗎？」

## 出事時

- **客戶不說話**：看輸入框上方有沒有「本地語音：單一女聲」那行；沒有的話你在雲端模式，檢查網路。再不行按「重新開始」——它現在會開一場全新的練習，不是清畫面而已。
- **講到一半重複播**：已修（同一句只播一次，見 commit `547f5c2`）；若又出現，是伺服器同時送了兩種事件，看 console 有沒有兩筆 `agent.response.final`。
- **虛擬人沒出現**：會自動退回靜態頭像，語音與對話不受影響，徽章會直說是哪一種。
